# Designer Studio

## 这是做什么的

这是一个给 Agent 用的“前端设计执行层”，专门服务内网环境。

它不和你争实现权，而是做三件高价值的事：

1. 先把离线 Tailwind 框架接进项目，确保实现层稳定  
2. 再从 69 套现成设计样式里快速收敛视觉方向  
3. 最后给出可直接引用的规范路径和人工预览链接，避免来回沟通损耗

你可以把它理解成：  
“给 Agent 的设计选型台 + 离线框架工具箱”，让前端产出既能落地，又不失风格。

## 你能获得什么

- 一份可立即落地的离线 `tailwind.min.css`
- 一套按行业分类整理好的样式样本库（`69` 套）
- 每套样式都含：
- `Preview`：亮色预览
- `Dark Preview`：暗色预览

说明：
- `DESIGN.md` 是 Agent 可引用的风格规范来源
- `preview.html` / `preview-dark.html` 仅供人类手动预览，不作为 Agent 的读取输入

## 怎么在对话里用

不需要手动执行命令，直接告诉 Agent 你的目标即可：

- `/designer-studio 把离线 tailwind 包接入当前项目`
- `/designer-studio 我做 AI 产品后台，从 AI & LLM Platforms 里挑 5 套先给我看`
- `/designer-studio 我想要类似 linear 的暗色工程感，给我可比较的 3 套链接`
