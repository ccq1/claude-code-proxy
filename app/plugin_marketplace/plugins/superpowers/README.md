# 超级力量（Superpowers）

## 1. 插件定位

`superpowers` 是一个面向编码代理的工程方法论插件。它把头脑风暴、需求澄清、实现计划、测试驱动开发、系统化调试、并行子代理协作、代码评审与分支收尾串成一套可复用工作流，让 Agent 更少跑偏、更稳地推进开发任务。

## 2. 核心能力

- 在真正写代码前先做需求澄清与方案讨论
- 把确认过的方案拆成细粒度、可验证的实现计划
- 推动 TDD、系统化调试和验证先行
- 在支持的平台上组织并行子代理协作与代码评审
- 在任务完成后做分支收尾、验证和交付整理

## 3. 适用场景

- 需求还比较模糊，需要先梳理边界和设计方向
- 功能较大，想先产出一个可执行计划再落地
- 代码容易返工，想强化 TDD、调试和评审纪律
- 希望让 Agent 的协作过程更规范、更可复盘
